== Project Panama
image::images/panama-canal.jpg[background, size=cover]

> Interconnecting JVM and native code

Deliverables:

* foreign function & memory API
* vector API

=== Timeline

JDK 21:

* foreign APIs in 3rd preview (https://openjdk.org/jeps/442[JEP 442])
* vector API in 6th incubation (https://openjdk.org/jeps/448[JEP 448])

JDK 25:

* foreign APIs are final (https://openjdk.org/jeps/454[JEP 454])

JDK 27:

* vector API in 12th incubation (https://openjdk.org/jeps/537[JEP 537]), +
  waiting for Valhalla's value types
