=== Summary

Value types in a nutshell:

* identity is often harmful for immutable classes
* value classes:
** are immutable classes without identity
** are compared by fields with `==`
** have some behavioral restrictions
** are otherwise regular classes
* the runtime can flatten and scalarize +
  value objects to improve performance

=== In JDK 28

Value types are a preview feature.

If enabled with `--enable-preview`:

* 30 JDK classes become value classes
* custom value classes with `value`

Experiment and give feedback!
