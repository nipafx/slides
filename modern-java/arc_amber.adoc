=== Patterns so far...

In `instanceof` and `switch`, patterns can:

* match against reference types
* deconstruct records
* nest patterns
* ignore parts of a pattern

In `switch`:

* refine the selection with guarded patterns

=== Constant checks

Constant patterns for simpler primitive checks:

```java
record Point(int x, int y) { }

var point = // ...
switch (point) {
	// record pattern
	case Point(var x, _) when x == 0 -> // ...
	// constant pattern (probably)
	case Point(0, _) -> // ...
}
```

Currently, only records can be deconstructed.

=== Deconstructible interfaces

Expand deconstruction to other types:

```java
// ↙ INTERFACE   ↙ state description
interface Point(int x, int y) {
	// state description implicitly requires:
	// int x();
	// int y();
}

// would allow
var point = // ...
switch (point) {
	case Point(var x, var y) -> // ...
}
```


=== Deconstruction on assignment

Often, there's no need for the conditional.

Deconstruction on assignment is unconditional:

```java
// `Point` is a type with state description
Point nextPoint() { /* ... */ }

// if you only need `x`
Point(int x, _) = nextPoint();
```

=== Reconstruction

If the type has a symmetrical construction protocol +
(like records):

```java
record Point(int x, int y) { }

var p0 = new Point(0, 0);
var p1 = p0 with { x = 1; };
```
