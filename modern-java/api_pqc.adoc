=== Post-quantum encryption

NIST standardized module-latice based algorithms:

* ML-KEM to secure symmetric keys (https://csrc.nist.gov/pubs/fips/203/final[FIPS 203])
* ML-DSA for digital signatures (https://csrc.nist.gov/pubs/fips/204/final[FIPS 204])

IETF developed a framework for +
hybrid key exchange schemes for TLS 1.3 (https://www.rfc-editor.org/info/rfc9954/[RFC 9954]).

=== PQC in Java

Java implements:

* ML-KEM (https://openjdk.org/jeps/496[JEP 496]) ㉔
* ML-DSA (https://openjdk.org/jeps/497[JEP 497]) ㉔
* hybrid key exchange for TLS 1.3 (https://openjdk.org/jeps/527[JEP 527]) ㉗
